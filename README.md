# Trade Activity

Локальная история сделок T‑Bank с группировкой позиций и помесячным отчётом.

## Структура

```text
backend/
  api/              HTTP: торговля, дневник, настройки
  services/         сценарии: позиции, дневник, синхронизация, экспорт
  domain/           расчёт позиций и правила определения выхода
  storage/          SQLite и обновление схемы
  brokers/          клиент T-Bank
  config.py         пути и локальная конфигурация
frontend/src/
  app/              маршрутизация страниц и левое меню
  features/
    trading/        позиции, таблица, колонки, API и стили
    journal/        список разборов, редактор, API и стили
    reports/        помесячный отчёт, API и стили
  shared/           общие компоненты, HTTP-клиент и форматирование
  main.jsx          точка входа React
tests/              проверки правил выхода и сохранности дневника
app.py              запуск Flask
pyproject.toml      зависимости Python
config.json         локальные настройки и токен (не в Git)
trade_activity.sqlite3  локальные данные (не в Git)
```

HTTP-обработчики вызывают сценарии из `services`. Сценарии используют расчёты
из `domain`, хранилище `storage` и при синхронизации — клиент из `brokers`.
Расчёты не обращаются к Flask, базе или сети. Пути к конфигурации и базе задаются
от корня проекта и не зависят от расположения модулей.

На фронтенде каждый раздел содержит свои компоненты, запросы и стили. В `shared`
находится код, который нужен нескольким разделам. Нового брокера следует добавлять
в `brokers`, а синхронизацию подключать через `services`; UI работает с общими позициями.
Приложение по-прежнему запускается одним процессом Flask (и Vite в режиме разработки).

## Первый запуск

Нужны Python 3.10+ и Node.js 20.19+ в ветке 20 либо 22.12+.
Все команды выполняются из корня проекта, если не указано иначе.
Python-зависимости описаны в `pyproject.toml`. Установка через `pip install -e .`
связывает окружение с исходниками проекта; приложение запускается из этого checkout.

macOS / Linux:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -e .
cd frontend
npm ci
npm run build
cd ..
```

Windows PowerShell:

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -e .
Set-Location frontend
npm ci
npm run build
Set-Location ..
```

Добавьте read-only токен T‑Invest API в `config.json`:

```json
{
  "tbank_token": "ваш токен",
  "port": 8000
}
```

Запуск:

```bash
# macOS / Linux
.venv/bin/python app.py
```

```powershell
# Windows PowerShell
.venv\Scripts\python.exe app.py
```

Откройте <http://127.0.0.1:8000>.

## Разработка фронтенда

Flask и Vite запускаются в двух терминалах:

```bash
# macOS / Linux (Windows: .venv\Scripts\python.exe app.py)
.venv/bin/python app.py
```

```bash
cd frontend
npm run dev
```

Интерфейс разработки: <http://127.0.0.1:5173>. Vite перенаправляет API-запросы во Flask.

После изменений соберите production-версию командой `npm run build`.

## Торговля и дневник

Левое меню сворачивается; его состояние сохраняется в браузере.

- **Торговля** (`/`) — факты по позициям и ссылка «Открыть разбор» для каждой позиции.
- **По месяцам** (`/monthly`) — сводный отчёт по закрытым позициям.
- **Дневник трейдера** (`/journal`) — причины входа, плановые стоп и тейк, причина
  выхода и комментарий к выходу. Выберите позицию и нажмите «Сохранить разбор».
  Есть поиск по инструменту, фильтры по счёту и наличию заметок.

Существующие заметки к входу и выходу доступны в дневнике. При запуске схема SQLite
обновляется автоматически с сохранением записей. Разбор хранится отдельно от фактов
сделки и связан с позицией. Стоп и тейк — записи плана; они не выставляют заявки брокеру.
Причина выхода оценивается автоматически по сохранённым стопу/тейку и ценам всех
исполнений с учётом лонга/шорта. Это предположение, а не подтверждённый тип заявки.
Если стоп или тейк не определён, по правилу журнала показано «Вышел руками»
(в экспорте источник `default_rule`); разные способы частичного закрытия
дают «Смешанный выход». Оценка пересчитывается после сохранения плана и входит в JSON-экспорт.
Алгоритм находится в `backend/domain/journal.py` и не зависит от Flask или SQLite.
Старые значения скрытых полей «Эмоции и дисциплина» и «Выводы» в существующей базе сохраняются.

Пока импорт поддерживает T-Bank; другие брокеры и демо-счета — следующий этап.

## Зачем оставлены тесты

`test_exit_reason.py` проверяет лонг/шорт, стоп и тейк, частичные выходы и числа
с пробелами — в том числе исправленную ошибку со стопом `214 550`.
`test_journal.py` проверяет сохранение разбора, обновление старой схемы без потери
заметок и неизменность торговых фактов. При перемещении кода эти проверки помогают
сразу обнаружить изменение поведения. Они используют стандартный `unittest`,
временную базу и не требуют токена, сети или дополнительных пакетов.

Запуск:

```bash
.venv/bin/python -m unittest discover -s tests -v
```
